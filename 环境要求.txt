一、系统级依赖（开发机必装）
========================================
1. Docker Desktop（含 Docker Engine + Docker Compose v2）最新稳定版
   - 一键拉起 MySQL / Milvus / Neo4j / Redis / MinIO
2. Python 3.11+           （后端 + AI）
3. Node.js 20 LTS+        （前端），包管理 npm 或 pnpm
4. Git
5. （可选）Neo4j Desktop 5.x  —— 若不通过 Docker 跑 Neo4j

========================================

- MILVUS_HOST/PORT
- NEO4J_URI/USER/PASSWORD
- REDIS_HOST/PORT
- MINIO_ENDPOINT/ACCESS_KEY/SECRET_KEY

========================================
七、数据准备（data/）
========================================
- data/suppliers/      种子供应商 30-50 家（CSV/JSON，来源 1688/立创挂牌）-> MySQL+Milvus
- data/alternatives/   替代料交叉引用 20-50 组（常见等效料）-> Neo4j
- data/dictionary/     标准字典（品类/参数/标准编码）-> MySQL

========================================
八、启动顺序
========================================
1. 复制 .env.example -> .env，填入 DASHSCOPE_API_KEY 等
2. cd deploy && docker-compose up -d        # 起 MySQL/Milvus/Neo4j/Redis/MinIO
3. cd api  && pip install -r requirements.txt
            && uvicorn main:app --reload    # 后端 :8000
4. cd web  && npm install && npm run dev    # 前端 :5173
5. 初始化种子数据（python scripts/seed.py，待开发）
6. 访问 http://localhost:5173
