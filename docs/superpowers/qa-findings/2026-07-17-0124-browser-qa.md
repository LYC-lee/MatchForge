### P1 高优先级

#### 产品与 BOM 页面存在运行时错误

- 页面/路径: `/products-bom`
- 复现步骤:
  1. 以任意 demo 企业登录
  2. 打开 `/products-bom`
- 预期结果: 产品列表与 BOM 明细稳定展示。
- 实际结果: Vite 控制台反复报错 `Cannot read properties of undefined (reading 'toLocaleString')`，来源 `web/src/views/ProductsBomView.vue:317:44`。页面停留在“加载 BOM 中...”或局部渲染不完整。
- 截图路径: `docs/superpowers/qa-findings/assets/2026-07-17-0112-browser-qa/robust-9003-products-bom.png`
- 可能原因: BOM item 某个数值字段为 `undefined`，模板直接调用 `toLocaleString()`。
- 建议修复方向: 对数量/价格/库存字段做空值兜底，或在 API adapter 层规范化为数字。
