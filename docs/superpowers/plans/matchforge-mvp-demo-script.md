# MatchForge MVP 演示脚本

> 日期: 2026-07-16
> 定位: 电脑制造产业链 AI 企业经营驾驶舱 MVP 演示闭环
> 演示时长: 约 3 分钟
> 推荐演示企业: **9003 鼎云整机制造有限公司** (ODM/EMS, 中游, 有完整缺件 + RFQ 闭环数据)

## 一、演示前置准备

### 1. 启动后端

```bash
cd MatchForge
python -m uvicorn api.main:main --host 127.0.0.1 --port 8000
```

- 首次启动 langgraph 冷导入约 150s, 属正常现象 (procure 路由优雅降级)。
- 数据库: SQLite (`data/knowledge.db`), 已种子化 36 家企业 + 9001-9006 产业链。
- 健康检查: `curl http://127.0.0.1:8000/api/v1/health` -> `{"status":"ok"}`

### 2. 启动前端

```bash
cd MatchForge/web
npm run dev
```

- 前端代理 `/api` -> `http://localhost:8000` (vite.config.ts)。
- 演示账号: `demo@matchforge.ai` / `demo12345` (或任意邮箱+密码注册)。
- 前端 token 自动注册为后端 demo 用户 (兼容无缝)。

### 3. 验证数据

- 确认 9003 鼎云整机有: 2 个产品 (DY-DT-Pro, DY-NB-Air), 5 个订单, 3 个缺件, 6 个推荐动作。
- 审核页需 admin token (`kb-admin-demo`), 前端已内置专用 admin axios 实例。

## 二、3 分钟演示路径

### Step 1: 进入经营驾驶舱 (0:00 - 0:20)

1. 登录后自动跳转 `/app` (经营驾驶舱)。
2. 左上角确认当前企业为 **鼎云整机制造有限公司**。
3. 如果不是, 用企业切换器选择 9003 鼎云整机。
4. **亮点**: 数据来源标签显示"实时接口", 表示数据来自真实后端。

**讲解要点**: "老板登录后第一眼看到的是自己企业的经营全貌 -- 订单、预测、产品、缺件、推荐动作, 不是营销页, 也不是采购搜索框。"

### Step 2: 查看订单和预测需求 (0:20 - 0:35)

1. 驾驶舱首页"订单与预测需求"表格。
2. 展示 5 个订单 (含 1 个紧急订单 DY-ORD-2026-001, 500 台)。
3. 展示 2 条预测需求 (2026-10 / 2026-11, 笔记本 400+300 台)。

**讲解要点**: "紧急订单标红, 预测需求单独标注置信度, 帮老板一眼分清'马上要交'和'未来要备'。"

### Step 3: 查看缺件风险 (0:35 - 0:55)

1. 驾驶舱"缺件与风险"面板, 展示 Top 5 缺件。
2. 点击任一缺件 (如 CPU-I7-13700 或 PCBA-DY-DT-Z690) 跳转缺件详情。
3. 或点击左侧导航"缺件与采购"。

**讲解要点**: "每个缺件标明缺口数量、影响订单、首选供应商, 老板不用问采购就知道缺什么、缺多少、影响谁。"

### Step 4: 查看产品 BOM (0:55 - 1:10)

1. 左侧导航"产品与 BOM"。
2. 展示 2 个在产产品 (DY-DT-Pro, DY-NB-Air)。
3. 点击产品展开 BOM 表: 零件号、品类、需求量、安全库存、首选供应商、关键件标记。

**讲解要点**: "每个产品需要什么零件、谁是首选供应商、哪些是关键件, 一张表说清楚。"

### Step 5: 触发 RFQ (1:10 - 1:35)

1. 在"缺件与采购"页面, 选中一个缺件。
2. 点击"从此缺件创建 RFQ"按钮。
3. 填写 RFQ 表单 (标题、数量、候选供应商 ID 如 9002)。
4. 点击"创建 RFQ"。
5. 创建成功后点击"发送给供应商"。

**讲解要点**: "从缺件到 RFQ 一键打通, 不用打开另一个系统。候选供应商可以直接带缺口信息一起发出去。"

### Step 6: 切换供应商查看线索 (1:35 - 1:50)

1. 左上角企业切换器, 切换到 **9002 创捷主板模组科技** (鼎云的上游)。
2. 左侧导航"供应商工作台"。
3. 查看收到的 RFQ 线索列表 (来自鼎云的 RFQ)。

**讲解要点**: "切换到供应商视角, 立刻看到买方发来的询价线索, 不是 mock, 是刚才那笔 RFQ 的真实数据。"

### Step 7: 提交报价 (1:50 - 2:10)

1. 在供应商线索页, 点击"提交报价"。
2. 填写单价、MOQ、交期、库存等信息。
3. 提交报价。

**讲解要点**: "供应商在线提交报价, 数据直接进后端, 买方马上能看到。"

### Step 8: 回到买方查看报价对比 (2:10 - 2:25)

1. 切换回 **9003 鼎云整机**。
2. 进入"缺件与采购", 滚动到 RFQ 列表。
3. 找到刚发送的 RFQ, 点击"报价对比"。
4. 展示报价对比表: 排名、供应商、单价、MOQ、交期、是否达标、最低价标记。

**讲解要点**: "买方看到所有报价横向对比, 最低价高亮, 是否达到目标价一目了然。"

### Step 9: 使用企业内部问答 (2:25 - 2:45)

1. 左侧导航"企业内部问答"。
2. 点击快捷问题或输入: "当前缺件会影响哪些订单？"
3. AI 基于企业私域知识库 (RAG) 回答。
4. 回答带"RAG"标签 (真实检索) 或"本地降级"标签 (后端不可用时)。

**讲解要点**: "企业内部 AI 助手只回答自己企业的问题, 不跨企业检索, 和上下游协同问答分开。"

### Step 10: 使用上下游协同问答 (2:45 - 3:00)

1. 左侧导航"上下游协同"。
2. 左侧选择一个直接上下游 (如创捷主板 -- 上游, 或星河数码 -- 下游)。
3. 切换"产品方面"/"业务方面"。
4. 提问: "有哪些可供型号和规格？"
5. AI 基于伙伴企业私域知识回答。

**讲解要点**: "只能问直接相关的上下游, 无关企业不在列表里。产品问答和业务问答边界清楚。"

## 三、审核管理 (加分项, 如有时间)

1. 左侧导航"审核管理"。
2. 展示审核队列: RFQ 供应商匹配、报价异常等。
3. 点击"通过"或"驳回" (可附备注)。

**讲解要点**: "运营/管理员可以看到系统自动产生的审核项, 异常报价 (超目标价 1.5 倍) 自动入队。"

## 四、当前未完成项

1. **企业内部问答 RAG**: 后端 RAG 依赖 Milvus/Embedding, 本地环境可能降级到模板回答 (带"本地降级"标签)。
2. **采购寻源 SSE 流程**: 仍保留旧 `/flow` 流程, 未深度集成到驾驶舱主线 (作为高级入口保留)。
3. **认证收紧**: 当前 admin 用 demo token (`kb-admin-demo`), 生产需真实登录流程。
4. **MySQL/Milvus 真实环境**: 本地 SQLite + local 向量库降级, 未在 Docker 生产环境验证。
5. **kpi_snapshots / risk_alerts**: Phase2 未包含 KPI/风险监控模型, 后续阶段。
6. **供应商产品管理**: SupplierProducts 页仍为旧 mock, 未接入真实产品接口。
