## 一、总体结论：风格上的五个核心差距

20 家头部产品呈现出高度一致的纪律，而 MatchForge 在五个维度上都有明确差距：

| 维度 | 头部企业的做法 | MatchForge 现状 | 差距定性 |
|------|--------------|----------------|---------|
| **强调色** | 「配给制」：每屏仅一个彩色焦点（Linear/Ramp/Mercury），渐变只留品牌层 | 靛蓝 + 靛紫渐变在按钮/徽章/卡片多处使用 | 🟡 风格稀缺性不足 |
| **主题策略** | 采购行业五标杆（Coupa/Ariba/Zip/商越/甄零）**全部浅色默认**；深色仅作可选主题且独立校准 | 深色唯一主题，且混入浅色遗留 global.css | 🔴 行业惯例背离 + 技术债叠加 |
| **深色实现** | 禁纯黑纯白、层级靠"更亮表面"、白色透明度阶梯（Arco: rgba 4/8/12/16%） | 背景五档色阶已有雏形，但硬编码色值 100+ 处绕过令牌 | 🟡 体系未闭环 |
| **数据排版** | 数字 `tabular-nums` + 右对齐、状态徽章"色字+20%透明底+40%透明边"公式（Stripe/Fiori） | 状态色多处硬编码、无数字字体纪律、urgent 排序还沉底 | 🔴 数据可信度受损 |
| **AI 表达** | 2025–2026 头部集体"去 sparkle 化"：渐变球/AI 紫/四角星退场，AI 感靠流式节奏 + 证据链（Perplexity 溯源栈） | 靛紫渐变作为 AI 视觉主语言、Agent 过程展示单薄、断流零反馈 | 🟡 审美滞后于趋势 |

## 二、风格优化建议（按优先级）

### P0 — 一个战略决策：主题策略

**头部证据**：Coupa、SAP Ariba、Zip、商越、甄零五家采购产品全部浅色默认（SAP 明确深色仅为低光环境可选且须过 WCAG）；采购是办公室长时使用 + 单据打印场景。
**反面证据**：Linear/Cursor/Raycast 证明深色可以做得很高级，但它们是开发者工具。

**建议**：MVP 阶段不必立刻推翻深色，但要把深色"做对"，并把浅色版列入路线图——

1. **短期（本周）**：先修深色质量债——拆除浅色 global.css（两套视觉语言并存比深色本身更伤），深色层级统一走"更亮表面"而非阴影，禁纯黑纯白。
2. **中期（下一迭代）**：令牌体系语义化重构（surface-0~4、白色透明度阶梯、语义色 alpha 派生），这一步做完，浅色主题就是"换一套种子值"的低成本事。
3. **长期**：浅色默认 + 深色可选，作为企业客户投标时的合规与习惯选项。

### P0 — 数据可信度（与功能修复联动）

1. **数字排版纪律**：金额/参数/单号统一 `font-variant-numeric: tabular-nums` + 右对齐（Stripe 公式）；参数对比表差异高亮。
2. **状态徽章公式化**：色字 + 同色系 20% 透明底 + 40% 透明边，全部状态（L1–L5 风险、线索状态、审核状态）收敛为一套生成函数，替代硬编码。
3. **风险语义色对齐行业**：参考 Fiori 五态（Negative/Critical/Positive…）图标+色字+标签，不整行染色；L5「仅参考」退出 danger 红（已在 P0 修复清单）。
4. **渐变退出语义区**：`--gradient-accent` 只保留在 logo/AI 徽章/生成态，工作界面主按钮改纯色。

### P1 — 密度与排版（对标国产 B 端）

1. **行高公式**：行高 = 字号 + 8（TDesign），收敛当前散乱行高。
2. **品牌灰阶**：靛蓝按 8–12% 混入灰阶（TDesign 品牌灰）——现有蓝灰背景正是雏形，写成令牌公式而非随手调。
3. **密度档位**：表格/表单提供"默认/紧凑"两档（AntD 双算法思路），驾驶舱默认紧凑、对话页默认宽松。
4. **驾驶舱一屏一主指标**：首屏只放「本期节约额 + 趋势」（Mercury 式），供应商端放「待办 RFQ + 截止时间」，其余降层级。
5. **表格规范**：禁用斑马纹（易误读选中态），发际线行分隔 + hover 态（Stripe/Ramp 共同纪律）。

### P1 — AI 对话与工作流表达（对标 AI 对话四标杆）

1. **AI 回复去气泡**：文档式排版、720–768px 限宽（ChatGPT），让规格表/对比表自由呼吸；用户消息保留轻气泡。
2. **溯源信任栈**（Perplexity 模式，最贴合采购场景）：关键论断挂内联来源 chip +「N 条依据」汇总行 + 审计视图——直接转译为替代料推荐/报价的采购依据留痕，这也是 B2B 信任设计的差异化武器。
3. **AI 过程可见**：寻源四步配低饱和语义色圆点 + 连接线（Cursor 时间线式），流式输出配节奏化光标，替代铺渐变。
4. **输入区「+」总入口**（Kimi 式）：BOM/规格书上传、询价模板、快速/深度模式聚合，中文用户零学习成本。

### P1 — 可访问性即投标资产

WCAG 2.2 AA 在头部企业采购中是硬性门槛，整改记录可直接转写 VPAT：双层焦点环（Vercel 公式 `0 0 0 2px 底色, 0 0 0 4px 品牌色`）、24px 触控目标、reduced-motion 降级、RFQ 免重复录入。—— 与前期审查 P1 完全重合，优先级上调。

### P2 — 品牌感与文案

1. **去开发者痕迹**：落地页"Ready for Spike"类文案重写（已列 P0 修复）；风格上"营销面华丽、产品面克制"是标杆共同纪律——渐变/光效只留落地页，产品内克制。
2. **中文排版**：禁用衬线正文进数据表格（Claude 书页感不适合 B2B），中西文混排按国产三体系规范。

## 三、该避的坑（20 家标杆的集体反面清单）

| 坑 | 说明 |
|----|------|
| ❌ "AI 模板三件套" | 纯黑底 + 霓虹渐变按钮 + 玻璃卡片进工作界面——Linear/Vercel/Cursor/Raycast 共同反对 |
| ❌ 深色 = 浅色反色 | AntD/TDesign/Arco 均为暗色独立校准色板与文字透明度 |
| ❌ Sparkle/AI 紫泛滥 | 2025–2026 头部 AI 品牌集体撤退四角星/紫光晕/渐变球 |
| ❌ 玻璃拟态进数据界面 | Apple 自家 Liquid Glass 都因对比度翻车，只能留营销面 |
| ❌ 斑马纹表格 | 易被误读为选中态，Stripe/Ramp 用发际线 + hover |
| ❌ 衬线正文进中文表格 | Claude 式书页感是消费级审美，B2B 密度要对标 Perplexity 报告体 |

## 四、与前期修复路线图的关系

本风格建议不改变 `docs/ui-audit/README.md` 的 P0 功能修复顺序，而是：
- **P0 风格项**（拆 global.css、渐变退出语义区、tabular-nums）可与功能 P0 同批进行，均是小改动高杠杆；
- **P1 令牌语义化重构**是两份报告的共同枢纽——做完它，浅色主题、密度档位、状态徽章公式全部解锁；
- 建议在功能修复告一段落后，安排一个「设计系统冲刺」专项执行本文 P0–P1。
