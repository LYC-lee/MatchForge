## 1. 总体链路

　　电脑制作全链路可以拆成三大段：

```text
上游：原材料 / 元器件 / 模组
  -> 中游：产品设计 / BOM / 采购 / 制造 / 测试
  -> 下游：品牌销售 / 渠道交付 / 售后维修 / 回收翻新
```

　　如果要建设产业链数据库，建议用"产业环节 + 公司 + 产品/服务 + 供需关系 + BOM/物料关系 + 价格/交期/认证/质量数据"的方式组织。

　　**2025年行业概况：** 2025年全球PC出货量超2.7亿台（Gartner）/2.847亿台（IDC），同比增长约9.1%。前五品牌依次为联想、HP、Dell、Apple、华硕。AI PC成为核心增长驱动力，AI服务器需求同时拉动上游元器件全链路景气。（来源：Gartner / IDC / TechSpot，2026-01-20）

## 2. 上游：原材料与基础材料

### 主要产业

- 半导体材料：硅片、光刻胶、靶材、电子特气、封装材料。
- 金属材料：铜、铝、钢材、镁铝合金。
- 塑胶材料：ABS、PC、阻燃塑料。
- 玻璃与陶瓷材料：屏幕玻璃、陶瓷电容材料。
- 化工材料：胶水、导热硅脂、涂层、清洗剂。

### 关键环节

- 原材料供应
- 材料检测
- 材料加工
- 原材料贸易与分销

### 关键物料/BOM关联

- **硅片 → 晶圆制造 → CPU/GPU/DRAM/NAND芯片**：12英寸硅片是先进制程芯片的基础材料，直接决定芯片产能。
- **光刻胶 → 晶圆制造光刻工序**：EUV光刻胶是7nm以下制程的关键耗材，成本占比高。
- **电子特气 → 刻蚀/CVD/掺杂工序**：高纯特气直接影响晶圆良率。
- **铜箔 → PCB制造 → 主板/显卡PCB**：电解铜箔是PCB导电层基础材料。
- **工程塑料（PC/ABS） → 机壳/键盘/连接器注塑**：阻燃PC/ABS是笔电机壳和内部结构件的主要材料。
- **玻璃 → 屏幕盖板/触摸屏**：Gorilla Glass等高强玻璃是笔电触控屏盖板核心材料。

### 供需关系与痛点

- **硅片集中度极高**：信越+SUMCO合计占全球60%以上，中国大陆12英寸硅片自给率仍低，国产替代是长期方向但良率爬坡缓慢。
- **光刻胶"卡脖子"**：EUV光刻胶几乎被日本企业垄断，中国国产光刻胶集中在i线/KrF层面，ArF/EUV仍需突破。
- **电子特气国产化加速**：华特气体等国产供应商在中低端特气已实现替代，但超高纯度品种仍依赖进口。
- **铜箔价格受铜价波动影响大**：铜价上涨直接推高PCB和线缆成本。
- **工程塑料阻燃等级要求趋严**：欧盟REACH/中国RoHS新规对阻燃剂限制加强，材料配方需持续迭代。

### 关键物料/BOM关联

- **CPU/GPU → 主板Socket/插槽 → 散热模组**：处理器选型决定主板设计、散热方案和电源规格，是BOM核心驱动项。
- **DRAM → 内存插槽/PCB层数**：内存容量和速率影响PCB设计规格和层数。
- **NAND/SSD → M.2/U.2接口 → 主板走线**：存储接口类型决定主板走线和空间布局。
- **PCB → 主板/显卡/服务器板 → SMT贴片**：PCB是所有电子元器件的载体，PCB规格直接决定可搭载元器件类型。
- **MLCC/电阻/电感 → PCBA BOM**：被动元件数量占BOM物料项数70%以上，单价低但缺料影响大。
- **连接器 → 整机内部/外部接口**：Type-C、HDMI、内存插槽等连接器决定整机I/O规格。
- **显示面板 → 整机BOM成本前5项**：面板是笔电BOM中成本占比最高的元器件之一（10-15%）。
- **电池 → 整机续航/安全认证**：电池规格影响整机续航和安规认证（UN38.3/IEC62133）。
- **散热模组 → 整机厚度/性能释放**：散热方案直接影响整机TDP设计和产品形态。

### 供需关系与痛点

- **AI芯片供不应求**：NVIDIA Blackwell/GB200需求远超产能，TSMC先进制程产能成为瓶颈；CoWoS先进封装产能同样紧张。
- **DRAM/HBM产能集中**：三星+SK hynix合计控制全球DRAM 76.7%，HBM几乎被两家垄断；PC端DRAM受服务器需求挤压，价格波动大。
- **PCB产能向中国大陆转移**：中国大陆PCB厂商（鹏鼎、深南）快速追赶台湾厂商，但高端IC载板（ABF）仍由Ibiden/欣兴主导。
- **被动元件MLCC寡头格局**：村田份额约40%，高端MLCC（01005/0201微型、高容）几乎被日韩垄断；国产MLCC在中低端已替代，高端仍需突破。
- **面板价格周期性强**：LCD面板价格受供需波动影响大；OLED渗透率提升但产能集中在三星/京东方。
- **连接器国产化程度低**：TE/Amphenol/Molex三家合计占全球连接器市场约40%+，中国大陆厂商（立讯/长盈）在中低端已替代，高速/射频连接器仍依赖进口。
- **散热方案升级紧迫**：AI服务器TDP从500W→1000W+，传统风冷已达极限，液冷方案（冷板/浸没式）渗透加速但成本高、标准化不足。

### 关键物料/BOM关联

- **品牌商研发 → 整机BOM定义**：品牌商定义产品规格（CPU型号/内存/存储/面板/电池），驱动整个BOM选型和成本结构。
- **ODM设计 → BOM替代料策略**：ODM负责BOM详细设计，需定义替代料清单（AVL）以应对缺料。
- **BIOS/固件 → 硬件兼容性**：BIOS版本需匹配CPU/内存/存储控制器，固件兼容性直接影响量产稳定性。
- **EDA工具 → PCB Layout/IC设计**：EDA工具决定设计效率和设计质量，Cadence/Synopsys几乎垄断先进IC设计。
- **工程验证 → BOM锁定**：EVT/DVT/PVT各阶段验证通过后，BOM逐步冻结，NPI阶段锁定量产BOM。

### 供需关系与痛点

- **品牌商-ODM议价权集中**：品牌商掌握产品定义和BOM标准，ODM利润率受压；ODM通过AI服务器等高附加值业务提升利润。
- **BIOS/固件生态高度垄断**：AMI/Insyde/Phoenix三家垄断x86 BIOS市场，国产BIOS几乎空白。
- **EDA工具"卡脖子"最严重**：Cadence+Synopsys合计占全球EDA市场约75%+，美国出口管制直接影响中国芯片设计能力。
- **工程验证周期长**：从EVT到PVT通常需3-6个月，AI PC新产品迭代加快，验证压力增大。

### 关键物料/BOM关联

- **BOM拆解 → 元器件寻源**：BOM每个物料行项目需要匹配供应商、获取报价、确认交期和MOQ。
- **替代料管理 → AVL（认可供应商清单）**：每个BOM物料需定义1-3个替代料，以应对缺料风险。
- **代理商库存 → 现货/期货采购**：Arrow/Avnet等授权代理提供期货采购；Digi-Key/Mouser提供小批量现货采购。
- **EMS采购体系 → 整机BOM集中采购**：Foxconn/Flex等EMS通过集中采购降低BOM成本，供应商管理能力是核心竞争力。
- **数据/情报平台 → BOM风险分析**：SiliconExpert/Z2Data等平台提供元器件生命周期状态、停产预警、替代料推荐。

### 供需关系与痛点

- **授权分销vs. 现货贸易二元结构**：授权代理（Arrow/Avnet）覆盖大规模采购，现货市场（华强北）覆盖小批量紧急采购，但价格透明度差异大。
- **缺料管理是核心痛点**：AI需求导致DRAM/HBM/MLCC等关键物料周期性短缺，采购方需建立多层替代料策略。
- **BOM成本透明度低**：品牌商、ODM、EMS之间的BOM成本信息不对称，难以实现全链路成本优化。
- **国产替代寻源需求强烈**：信创政策推动国产元器件替代，但国产器件参数/质量数据不透明，替代验证周期长。
- **元器件数据分散**：Octopart/Findchips等平台覆盖国际品牌较好，但国产元器件数据覆盖不足，需多平台整合。

### 关键物料/BOM关联

- **PCB制造 → 主板/显卡/服务器板**：PCB是SMT贴片的基板，PCB层数/材料/线宽线距决定可搭载元器件规格。
- **SMT贴片 → PCBA BOM**：SMT贴片将BOM中的IC/被动元件/连接器贴装到PCB上，形成PCBA。
- **整机组装 → 完整BOM**：整机组装将PCBA+面板+电池+散热+结构件+线缆组合为整机，对应完整BOM。
- **测试设备 → BOM验证**：测试设备用于验证PCBA和整机BOM中每个物料的功能和可靠性。
- **自动化设备 → 制造工艺BOM**：自动化设备对应产线工艺BOM（工装/夹具/治具/程序），与产品BOM关联。

### 供需关系与痛点

- **代工产能向东南亚转移**：受关税和地缘政治影响，Compal扩充越南产能，Foxconn/Quanta在印度/越南扩产，中国大陆代工优势受挑战。
- **AI服务器代工利润高但技术门槛高**：Foxconn独占NVIDIA GB200 NVL72组装，Quanta跟进GB300，传统笔电代工利润率受压（3-5%），AI服务器利润率显著更高。
- **PCB产能过剩vs. 高端PCB紧缺**：中低端PCB产能过剩，但AI服务器用高多层板/HDI板产能紧缺，深南/鹏鼎受益。
- **SMT设备被日企垄断**：Fuji/Panasonic/Yamaha/JUKI四家占全球SMT贴片机市场约80%+，ASMPT在先进封装设备领域领先。
- **测试设备国产化率低**：Teradyne/Advantest垄断半导体测试机市场，国产华峰测控仅覆盖模拟测试机。

### 关键物料/BOM关联

- **IQC → 来料BOM验证**：IQC对BOM中每个来料物料进行规格/外观/电性能检验，不合格物料触发退货或替代料流程。
- **IPQC → 制程BOM追溯**：IPQC监控SMT/组装过程中BOM物料的正确性和工艺参数，不良品需追溯到物料批次。
- **OQC → 整机BOM验证**：OQC对整机BOM配置进行最终验证（CPU/内存/存储/面板型号与订单一致性）。
- **认证 → BOM合规性**：CE/FCC/RoHS/REACH认证要求BOM中所有物料符合环保和安规要求，需追溯到材料成分。
- **FA → BOM缺陷分析**：失效分析对不良品进行根因定位，可能追溯到BOM中特定物料批次或供应商。

### 供需关系与痛点

- **AI产品认证标准缺失**：AI PC/AI服务器的能效/安全/AI合规认证标准尚未成熟，检测机构面临新标准制定需求。
- **质量追溯数字化程度低**：多数制造企业质量数据仍以纸质或孤立系统记录，全链路批次追溯能力不足。

### 关键物料/BOM关联

- **PC品牌 → 整机SKU/BOM配置**：品牌商定义整机SKU和配置选项（CPU/内存/存储/面板），每个SKU对应一个BOM版本。
- **电商渠道 → SKU/BOM映射**：电商平台以SKU为单位销售，SKU需映射到BOM版本以确保发货配置正确。
- **企业渠道 → 定制BOM**：企业级客户可能要求定制配置（如更高内存/特殊接口），需对应定制BOM。
- **售后维修 → 备件BOM**：售后维修需备件BOM（维修物料清单），包含可替换部件型号和兼容性信息。
- **二手回收 → BOM估值**：二手回收定价需基于整机BOM配置和使用状况评估残值。

### 供需关系与痛点

- **AI PC换机周期启动**：Windows 10停止支持（2025年10月）+ AI PC新需求驱动2025年PC出货增长9.1%，但消费者对AI功能认知和付费意愿仍待验证。
- **中国市场国补政策推动增长**：中国大陆PC市场Q2 2025同比增长12%，国补政策（以旧换新）推动下半年增长，华为受益国产替代份额升至12%。
- **电商渠道价格战激烈**：京东/天猫/拼多多竞争加剧，PC品牌利润率受压；品牌商通过AI PC高溢价产品改善毛利。
- **物流成本与时效**：顺丰/京东物流/菜鸟竞争激烈，智能化（AI算法/无人车/无人机）降本增效成为差异化方向。
- **售后维修标准化不足**：第三方维修质量参差不齐，品牌官方售后成本高但消费者信任度高；二手回收定价透明度低。

### 9.2 最适合 MatchForge 先切入的环节

　　结合当前项目的 AI 寻源能力，建议先做这一段：

```text
产品/BOM
  -> 缺料识别
  -> 替代料推荐
  -> 供应商匹配
  -> RFQ 询价
  -> 报价比价
  -> 采购决策
```

　　原因是这段痛点明确，数据可积累，和现有"自然语言需求解析、替代料推荐、供应商匹配、询价单生成"的产品能力最匹配。

### 9.3 推荐分阶段落地

| 阶段 | 建议目标 | 核心数据 |
|---|---|---|
| Phase 1 | 元器件寻源与替代料 | 公司、供应商、物料、替代关系、RFQ |
| Phase 2 | BOM 与配置管理 | 整机型号、BOM 版本、兼容规则、成本 |
| Phase 3 | 采购与库存 | PO、报价、库存、批次、交期、缺料预警 |
| Phase 4 | 制造与质量追溯 | 工单、工序、测试、序列号、质检、RMA |
| Phase 5 | 渠道与售后 | 销售订单、物流、保修、维修、回收 |

## 10. 产业链图谱建模方向

　　如果后续要做知识图谱，可以把关系抽象成：

```text
公司 -> 生产 -> 产品/物料
公司 -> 供应 -> 品类/品牌
产品 -> 属于 -> 品类
产品 -> 用于 -> BOM
产品 -> 可替代 -> 产品
产品 -> 兼容 -> 产品/平台
BOM -> 属于 -> 整机型号
供应商 -> 报价 -> 物料
采购方 -> 发起 -> RFQ
RFQ -> 匹配 -> 供应商
工单 -> 消耗 -> BOM/物料批次
整机序列号 -> 追溯 -> BOM/批次/测试记录
```

　　这套关系可以支撑后续的 AI 问答、替代料推荐、供应商匹配、风险预警和产业链地图展示。
