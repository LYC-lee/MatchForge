# 电脑制作全链路产业链分析

> 本文用于梳理电脑从原材料、核心零部件、设计研发、采购寻源、制造组装、质量认证到销售售后的完整产业链，并列出每个环节可重点调研的代表公司。公司列表用于产业研究和数据库建设参考，不构成投资、采购或合作背书。

## 1. 总体链路

电脑制作全链路可以拆成三大段：

```text
上游：原材料 / 元器件 / 模组
  -> 中游：产品设计 / BOM / 采购 / 制造 / 测试
  -> 下游：品牌销售 / 渠道交付 / 售后维修 / 回收翻新
```

如果要建设产业链数据库，建议用“产业环节 + 公司 + 产品/服务 + 供需关系 + BOM/物料关系 + 价格/交期/认证/质量数据”的方式组织。

- 塑胶材料：ABS、PC、阻燃塑料。
- 玻璃与陶瓷材料：屏幕玻璃、陶瓷电容材料。
- 化工材料：胶水、导热硅脂、涂层、清洗剂。

- 原材料供应
- 材料检测

## 3. 上游：核心元器件与模组

### 主要产业

- 计算芯片：CPU、GPU、芯片组、AI 加速芯片。
- 存储：DRAM、NAND Flash、SSD、HDD。
- 主板相关：PCB、PCBA、电源管理 IC、网卡、声卡、接口芯片。
- 被动元件：电容、电阻、电感、磁珠。
- 连接器与线束：板对板、Type-C、HDMI、内存插槽、排线。
- 显示与交互：显示屏、摄像头、麦克风、扬声器、键盘、触控板。
- 电源与散热：电池、电源适配器、风扇、热管、均热板、导热材料。
- 结构件：外壳、机箱、转轴、支架、冲压件、CNC 件。

## 9. 数据库建设建议

### 9.1 建议优先沉淀的实体

| 数据实体 | 说明 |
|---|---|
| 公司 | 企业名称、类型、地区、主营业务、资质、上下游角色 |
| 产业环节 | 原材料、元器件、模组、设计、采购、制造、测试、认证、渠道、售后 |
| 产品/物料 | 型号、品牌、规格参数、生命周期、认证、文件 |
| BOM | 整机型号、版本、物料清单、用量、替代策略 |
| 供应能力 | 供应商、品类、品牌覆盖、MOQ、交期、区域、历史表现 |
| 询价与报价 | RFQ、供应商报价、有效期、交期、付款条件 |
| 采购与库存 | PO、入库、库存、批次、序列号、在途、锁定库存 |
| 制造过程 | 工单、工序、产线、设备、测试、返工、报废 |
| 质量追溯 | IQC、IPQC、OQC、FCT、Burn-in、FA、RMA |
| 文档资料 | Datasheet、证照、认证、检测报告、合同、图片 |

### 9.2 最适合 MatchForge 先切入的环节

结合当前项目的 AI 寻源能力，建议先做这一段：

```text
产品/BOM
  -> 缺料识别
  -> 替代料推荐
  -> 供应商匹配
  -> RFQ 询价
  -> 报价比价
  -> 采购决策
```

原因是这段痛点明确，数据可积累，和现有“自然语言需求解析、替代料推荐、供应商匹配、询价单生成”的产品能力最匹配。

### 9.3 推荐分阶段落地

| 阶段 | 建议目标 | 核心数据 |
|---|---|---|
| Phase 1 | 元器件寻源与替代料 | 公司、供应商、物料、替代关系、RFQ |
| Phase 2 | BOM 与配置管理 | 整机型号、BOM 版本、兼容规则、成本 |
| Phase 3 | 采购与库存 | PO、报价、库存、批次、交期、缺料预警 |
| Phase 4 | 制造与质量追溯 | 工单、工序、测试、序列号、质检、RMA |
| Phase 5 | 渠道与售后 | 销售订单、物流、保修、维修、回收 |

## 10. 产业链图谱建模方向

如果后续要做知识图谱，可以把关系抽象成：

```text
公司 -> 生产 -> 产品/物料
公司 -> 供应 -> 品类/品牌
产品 -> 属于 -> 品类
产品 -> 用于 -> BOM
产品 -> 可替代 -> 产品
产品 -> 兼容 -> 产品/平台
BOM -> 属于 -> 整机型号
供应商 -> 报价 -> 物料
采购方 -> 发起 -> RFQ
RFQ -> 匹配 -> 供应商
工单 -> 消耗 -> BOM/物料批次
整机序列号 -> 追溯 -> BOM/批次/测试记录
```

这套关系可以支撑后续的 AI 问答、替代料推荐、供应商匹配、风险预警和产业链地图展示。
